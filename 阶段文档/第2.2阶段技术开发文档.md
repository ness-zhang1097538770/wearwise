# 第 2.2 阶段技术开发文档｜AIGC 静态成像（Avatar + 造型上身图）

> 配套文档：PRD V2.0、通用技术栈手册、《技术适配声明》、第 2.1 阶段文档
> 本文档只覆盖第 2.2 阶段，不提前实现 2.3（视频/购物分析）。

## 一、阶段目标

- **交付范围**：Avatar 数字形象生成（4 候选 → 选 1 主形象）+ 造型上身图（IMG-03，用主形象作参考图生成）。
- **阶段产物**：Avatar 生成与选择能力、造型上身图能力、最小验收界面更新、mock 测试、证据包。
- **验收标准**：
  1. 填体型参数 → 生成 4 个候选形象；
  2. 选 1 个设为主形象，后续复用保持一致；
  3. 对穿搭方案点"生成上身图"→ 生成该人物穿该搭配的全身图；
  4. 无主形象时生成上身图给出明确提示；
  5. 数据重启后可恢复。
- **明确不做**：真人照片通路（V1.5）、商品上身图/新旧对比图（IMG-07/08，与购物分析一起放 2.3）、发型妆容、场景沉浸图、视频。
- **主链路片段**：填参数 → 生成候选 → 选主形象 → 生成上身图。

## 二、技术适配摘要

- 沿用 2.1 技术栈（FastAPI + SQLite + 火山方舟 Seedream）。
- 新增按需能力：图生图（Seedream 参考图 `image` 参数传 data URL）。
- 开发路径：纵向切片。

## 三、技术栈与模型

- 图像生成：Doubao-Seedream-5.0-pro（接入点 `IMAGE_MODEL`），尺寸 1920×1920。
- 图生图：Seedream 支持 `image` 参数传参考图（data URL），已验证通过。
- 一致性：MVP 用参考图方案（主形象图作为参考图注入），不自训 LoRA。

## 四、环境与配置

- 沿用 `.env`（火山方舟 Key + 3 个接入点 ID），无新增配置。

## 五、项目结构

- 新增：`app/services/avatar_service.py`、`app/api/avatars.py`、`app/services/prompts/avatar.txt`、`avatar_outfit.txt`、`app/models` 增 `Avatar` 表、`tests/test_avatar.py`。

## 六、数据、资产与状态

- 新增表 `avatars`：id、params_json（体型参数）、candidates_json（[{index,image_url}]）、selected（选中 index）、is_primary、status（pending/running/done/failed）、error、created_at。
- 资产：候选图/上身图存 `data/generated/`（`avatar_{id}_{i}.jpg`、`avatar_outfit_{task_id}.jpg`）。
- 状态机：avatar `pending→running→done/failed`；主形象唯一（select 时先取消旧主形象）。

## 七、API 设计

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /api/v1/avatars | 填参数 → 后台并行生成 4 候选 |
| GET | /api/v1/avatars | 列表 |
| GET | /api/v1/avatars/{id} | 单形象 |
| POST | /api/v1/avatars/{id}/select | 选候选 index → 设主形象 |
| DELETE | /api/v1/avatars/{id} | 删除 |
| POST | /api/v1/outfits/{id}/items/{idx}/avatar-image | 用主形象生成上身图（提交+轮询） |

## 八、Prompt 设计

- `avatar.txt`：体型参数 → 全身数字形象，面部简化、禁止美化（瘦/高/白/磨皮）。
- `avatar_outfit.txt`：主形象参考图 + 穿搭清单 → 保持体型外貌一致的上身图，禁止美化。
- 护栏：禁止美化词已在 prompt 内写明；输出层 AI 标识在界面展示。

## 九、验收界面

- `index.html` 新增「数字形象」卡（填参数→生成→点候选选中）+ 每套穿搭新增「生成上身图」按钮（轮询任务）。

## 十、测试要求

- mock 测试（21 项）：新增 Avatar 生命周期、选主形象、非法序号、上身图成功、无主形象失败提示。
- 真实冒烟：Avatar 并行 4 候选、选主形象、上身图生成（参考图一致性）已通过。

## 十一、验收清单（产品经理照着点）

1. 打开 http://127.0.0.1:8001/；
2. 「数字形象」卡填身高/体型/发色 → 点"生成 4 个候选" → 约 1 分钟看到 4 张候选；
3. 点一个候选 → 提示"已设为主形象"；
4. 右侧生成一套穿搭 → 点"生成上身图" → 约 40 秒看到"这个人"穿这套衣服的图；
5. 刷新页面 → 主形象和上身图仍在。

## 十二、风险与待确认项

- 参考图一致性为"视觉近似"，非 100% 一致（PRD 已声明不承诺实物一致）。
- Avatar 面部已做简化约束，但生成结果仍需人工抽检（暴露/畸变）。
- 无必须由产品经理决定的新问题。

## 十三、交接给下一阶段
