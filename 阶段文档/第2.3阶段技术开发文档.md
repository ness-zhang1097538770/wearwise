# 第 2.3 阶段技术开发文档｜动态试穿视频 + 购物防冲动分析

> 配套文档：PRD V2.0、通用技术栈手册、《技术适配声明》、第 2.1/2.2 阶段文档
> 本文档只覆盖第 2.3 阶段，是 MVP 最后一个子阶段。

## 一、阶段目标

- **交付范围**：
  1. 动态试穿视频（VID-01）：用造型上身图作首帧 → Seedance 图生视频（3–5s 转身/走动），异步执行；
  2. 购物防冲动分析：上传商品截图 → AI 提取商品信息 → 与衣柜匹配 → 输出分析报告（匹配度/重复度/可搭配造型/单次穿着成本估算/决策建议）。
- **阶段产物**：视频异步任务框架、购物分析报告、验收界面更新、mock 测试、证据包。
- **验收标准**：
  1. 上身图 → 提交视频任务 → 轮询 → 得到 3–5s 视频；
  2. 上传商品图 → 输出分析报告（含建议"值得考虑/建议等待/与现有衣物重复"）；
  3. 数据重启后可恢复；视频默认 30 天清理（本期先记录创建时间）。
- **明确不做**：面料动态展示（VID-02 简化，MVP 先用 VID-01 验证视频链路）、一周 Lookbook、旅行 Lookbook、浏览器插件、商品链接解析（MVP 仅截图/照片）。
- **主链路片段**：上身图 → 视频；商品截图 → 分析报告。

## 二、技术适配摘要

- 沿用 2.1/2.2 技术栈；新增视频生成（Seedance）与购物分析（文字+视觉复用已有模型）。
- 开发路径：纵向切片。

## 三、技术栈与模型

| 用途 | 模型 | 接入点 |
| --- | --- | --- |
| 视频生成（图生视频 i2v） | Doubao-Seedance-1.0-lite-i2v（图生视频专用、成本低） | `VIDEO_MODEL` |
| 商品信息提取 | Doubao-Seed-2.1-lite（视觉，复用 `VISION_MODEL`） | 已有 |
| 购物分析报告 | Doubao-Seed-2.1-lite（文字，复用 `TEXT_MODEL`） | 已有 |

- 视频 API：火山方舟 Seedance 异步任务（提交 → 轮询 → 取视频 URL）。

## 四、环境与配置

- 新增 `.env` 配置项：`VIDEO_MODEL`（Seedance 接入点 ID）。

## 五、项目结构

- 新增：`app/services/video_service.py`、`app/services/analysis_service.py`、`app/api/analysis.py`、`app/services/prompts/analysis.txt`、`video.txt`、`tests/test_analysis.py`、`tests/test_video.py`。

## 六、数据、资产与状态

- 复用 `tasks` 表：`kind=video`（动态试穿视频，result_json 存 video_url）；`kind=analysis`（购物分析，同步 SSE 不落任务）。
- 新增表 `analyses`：id、product_json（商品信息）、report_json（分析报告）、image_path、created_at。
- 状态机：video task `pending→running→done/failed`（失败不扣额度）。

## 七、API 设计

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /api/v1/outfits/{id}/items/{idx}/video | 用该套上身图生成视频（提交+轮询，返回 task_id） |
| POST | /api/v1/analysis | 上传商品截图 → SSE 流式返回分析报告 |
| GET | /api/v1/analysis | 分析历史列表 |

- 视频需先有该套的上身图（否则提示先生成上身图）。

## 八、Prompt 设计

- `video.txt`：首帧图 + "人物自然转身/缓慢走动，保持体型外貌一致，面料自然摆动，3-5 秒"。
- `analysis.txt`：商品信息 + 衣柜清单 → 报告 JSON（匹配度/重复度/可搭配造型/单次穿着成本/建议），中性表达，禁止劝买。

## 九、验收界面

- 每套穿搭新增「生成试穿视频」按钮（先有上身图才可用）；新增「购物分析」卡（上传商品图 → 看报告）。

## 十、测试要求

- mock 测试：视频任务状态流转、分析报告解析、商品信息解析、错误路径。
- 真实冒烟：视频生成（Seedance i2v）、购物分析报告（视觉+文字）。

## 十一、验收清单（产品经理照着点）

1. 生成一套穿搭 → 生成上身图 → 点「生成试穿视频」→ 约 1-3 分钟得到 3-5s 视频；
2. 购物分析卡上传一张商品图 → 看到分析报告（匹配度/重复度/建议）；
3. 重启后视频和分析历史仍在。

## 十二、风险与待确认项

- 视频成本高（约 0.5-3 元/条），已在额度体系内；真实成本待冒烟校准。
- 无必须由产品经理决定的新问题。

## 十三、交接给下一阶段（阶段 3 正式前端）

- 后端 MVP 全部能力就绪：衣柜、穿搭、平铺图、Avatar、上身图、视频、购物分析；阶段 3 用 Next.js 正式前端复用这些 API。
