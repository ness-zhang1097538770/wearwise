## 必须问（本轮 5 个）

### 问题 1：MVP 阶段做成什么终端？
- 为什么重要：PRD 写"移动端 App 为主"，但直接做原生 App 会让 MVP 周期和成本翻倍，且核心价值（AIGC 成像）在手机浏览器里也能完整演示。
- 选项：A. 先做 Web 版 MVP（手机浏览器可用）／ B. 直接做移动 App（React Native）／ C. Web + 桌面
- 推荐：**A. 先 Web MVP**。成本低、迭代快、上传照片/生成图视频在浏览器可完整跑通，App 等核心链路验证通过后再做。
- 不选的后果：选 B 会显著拉长 MVP、增加成本，核心价值未验证就铺开正式前端，违反"核心链路未验证不铺开"底线。

### 问题 2：敏感数据（身体照片 / 衣柜 / 消费记录）是否必须全部留在国内？
- 为什么重要：直接决定成像模型供应商选国内还是海外，也关系隐私合规。你的产品主打"隐私敏感型用户"，数据出境会动摇这个卖点。
- 选项：A. 全部国内（推荐）／ B. 可用海外供应商／ C. 敏感数据国内、成像可海外
- 推荐：**A. 全部国内**。国内模型（可灵 / 即梦 / 豆包等）图、视频能力已足够，且符合隐私定位。
- 不选的后果：选 B/C 引入数据出境合规风险，隐私卖点打折扣，且海外供应商时延更高、成本更难控。

### 问题 3：MVP 阶段月度模型/云成本上限定多少？
- 为什么重要：视频生成成本高、易失控，必须设熔断上限。PRD 有量级估算但订阅价和总预算未定。
- 选项：A. 500 元/月封顶（推荐）／ B. 1000 元/月／ C. 不确定，由我按量级定
- 推荐：**A. 500 元/月**。按 PRD 量级（免费 15 图+2 视频、Plus 200 图+40 视频）足够内部试用 + 早期小规模验证。
- 不选的后果：无上限则视频成本可能吃穿毛利；上线时加成本监控看板与额度熔断即可兜底。

### 问题 4：公司能否办理云平台企业实名认证？
- 为什么重要：默认上线路线需要企业实名认证（通常要几天），建议现在就去办，与开发并行，避免上线被卡。
- 选项：A. 能办（推荐，现在去办）／ B. 只能个人认证／ C. 不确定
- 推荐：**A. 能办**，现在就去办。
- 不选的后果：个人认证在并发、实名、支付能力上受限，可能阻塞阶段 4 上线。

### 问题 5：MVP 试穿形象通路是否只做 Avatar（不上真人照片）？
- 为什么重要：真人照片涉及敏感数据分级管理、内容审核、未成年人限制等，会显著膨胀 MVP 范围。
- 选项：A. 仅 Avatar（推荐）／ B. Avatar + 真人照片
- 推荐：**A. 仅 Avatar**。隐私风险低、一致性更好、开发量小；真人通路放 V1.5（PRD 待决策项 #1 也是这个建议）。
- 不选的后果：选 B 会让 MVP 范围膨胀，真人照片的合规与审核工作会拖慢上线。

## 可默认（已用默认值填上，请确认一次）

| 缺口 | 默认值 | 理由 |
| --- | --- | --- |
| 视频是否进 MVP | 进，但只做 3s 转身一种形态 | PRD 待决策项 #2 建议"进"，视频是差异化最大来源 |
| 成像触发方式 | 平铺图自动生成；上身图/视频点击触发 | PRD 待决策项 #3 建议，平衡体验与成本 |
| 免费额度 | 15 张图 + 2 条视频/月 | PRD 待决策项 #6 建议，够体验一次完整购买决策 |
| 生成物社交分享 | 允许分享，但强制保留 AI 标识，不做社区 | PRD 待决策项 #7 建议，避免定位漂移 |
| 一致性方案 | MVP 用通用参考图，不自训 LoRA | PRD 待决策项 #5 建议；一致性投诉率 >8% 再启动自训 |
| 视频供应商 | 先按"2 家国内 + 1 家海外备用"方向实测，主路由实测定 | PRD 待决策项 #4 建议；最终以"数据地域"结论为准 |
| 登录方式 | 游客体验 + 手机号注册 | PRD 已写"注册或游客体验"，补全为手机号 |
| 上传文件大小 | 衣物照片 ≤ 20MB/张 | 模板默认值，AIGC 成像原图够用 |
| MVP 目标用户量 | 内部试用 + 小规模（<100 人） | 阶段 2/3 用，无需大量并发 |
| 响应时间要求 | 图 ≤10s、视频 ≤90s（异步+通知） | PRD「性能与时延目标」已定 |
| 生成物存储周期 | 默认 30 天自动清理，收藏永久保留 | PRD「隐私与安全」已定 |
